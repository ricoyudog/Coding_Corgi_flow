1. Require Node.js >=20.19.0, OpenSpec >=1.6.0 <2.0.0, and `corgispec@4.0.0-rc2`.
2. Run `corgispec doctor --path <project>` before writes.
3. For a fresh/update target, run `corgispec bootstrap --target <project> --mode auto`.
4. For v3, first require no active Change/nonterminal run, then dry-run and execute `corgispec bootstrap --target <project> --migrate-v4`.
5. Never offer a Memory/Wiki opt-out. Bootstrap must create or preserve the complete mandatory knowledge structure and fixed startup protocol.
6. Pass explicit platform, scope, schema, tracker, and integration-branch choices through when supplied; otherwise use CLI defaults/prompts.
7. Read the install report and surface every backup or conflict. Never force a stopped transaction.
8. Rerun doctor and verify the RFC contract, Foundation draft, Memory/Wiki, managed assets, and each selected platform independently.
9. Tell the human to complete, validate, interactively accept, commit, and merge `RFC-0001-project-foundation` before Propose.
10. Never reconstruct asset installation, RFC approval, lifecycle state, tracker writes, or archive behavior outside the CLI.

Hooks remain opt-in for hookless projects. Once enabled, SessionStart/PostCompact synthesize Run Contract v3 context and report Session Bridge drift.
